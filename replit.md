# replit.md

## Overview

The Madonna Shop is a complete static website for a Catholic religious goods store located in El Paso, Texas. The site serves as a digital presence for a brick-and-mortar shop that sells religious books, gifts, devotional items, and Catholic merchandise. The website provides essential business information, showcases products, captures customer reviews, and facilitates contact with the store. The site is fully functional, SEO-optimized, and ready for deployment with placeholder elements clearly documented for easy replacement.

## User Preferences

Preferred communication style: Simple, everyday language.
Project approach: Static HTML/CSS/JS implementation (not Next.js) for simplicity and easy hosting.

## System Architecture

### Frontend Architecture
- **Pure Static HTML/CSS/JS**: The site uses vanilla HTML5, CSS3, and JavaScript without any framework dependencies, ensuring fast loading times and easy hosting
- **Multi-page Structure**: Separate HTML files for each main section (index, about, products, contact, reviews, privacy) for clear navigation and SEO benefits
- **Responsive Design**: CSS-based responsive layout using flexbox and media queries to work across all device sizes
- **Progressive Enhancement**: Core functionality works without JavaScript, with JS providing enhanced interactions

### Styling System
- **CSS Custom Properties**: Centralized color scheme and spacing system using CSS variables for consistent theming
- **Component-based CSS**: Modular CSS classes for buttons, cards, forms, and layout components
- **Catholic Store Branding**: Navy (#1E2A44), Gold (#C6A85B), and Ivory (#FAF7F2) color palette reflecting reverent, traditional aesthetics
- **Typography**: Inter font family from Google Fonts for modern readability

### JavaScript Features
- **Store Hours Display**: Dynamic calculation and display of current store hours with today highlighting
- **Contact Form Handling**: Client-side form validation and submission (currently placeholder, ready for webhook integration)
- **Review Button Setup**: Google Review link integration (placeholder for actual Google Place ID)
- **Responsive Navigation**: Mobile-friendly navigation interactions

### SEO Architecture
- **Structured Data**: JSON-LD schema markup for local business information
- **Meta Tags**: Comprehensive Open Graph and Twitter Card tags for social sharing
- **Semantic HTML**: Proper heading hierarchy and semantic elements for accessibility and SEO
- **Local SEO Focus**: El Paso, Texas geographic targeting and Catholic religious goods keywords

### Content Management
- **Static Content**: All content is directly in HTML files for easy editing
- **Placeholder System**: Clearly marked placeholders for images, Google review links, and contact form integration
- **Admin Documentation**: Detailed notes in admin-notes.md for replacing placeholder elements
